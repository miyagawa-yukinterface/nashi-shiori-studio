ゴーストの設定

ランダムトーク

直近に出したトークを、この数だけ次の抽選からはずします。おまかせのときはトーク数の半分（最大8）です。

立ち絵の画像

用意した PNG を割り当てられます。えらばなかった番号は、下の色で自動生成します。

見た目（仮シェル）

絵を用意していないときは、この色でかんたんな立ち絵を自動生成します。

変数

好感度やフラグなど、ゴーストが覚えておく値です。終了時に自動で保存されます。

チェック

おかしなところを探します。クリックすると、そのブロックまで移動します。

SSP に入れる

SSP の ghost フォルダへ直接書き出して、そのまま切り替えます。

フォルダ／.nar に書き出す

読み込み

書き出し済みのゴースト（ghost.json）を読み込んで編集できます。

つかいかた

  1. イベントから「起動したとき」などをキャンバスにドラッグします。
  2. その下にセリフの「…と話す」ブロックをつなげます。
  3. ためすタブの ▶ で動きを確認します。
  4. 「なでられたとき」などのマウス操作は、あたま・かお・むねといった場所ごとに 分けて反応させられます（仮シェルにも当たり判定が入っています）。
  5. チェックタブに気になるところが出ます。クリックするとその場所へ移動します。
  6. 用意した絵を使うときは、ゴーストタブの「立ち絵の画像」で PNG をえらびます。
  7. 書き出しでフォルダか .nar を作り、SSP にドラッグ＆ドロップで入れます。

栞について

書き出したゴーストは nashi.dll（なし栞）で動きます。会話データは ghost/master/ghost.json に入っていて、SSP を動かしたまま書き出し直すと 数秒で自動的に読み込み直されます。
