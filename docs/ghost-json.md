# ghost.json の仕様

なし栞（`nashi.dll`）は、自分と同じフォルダにある **`ghost.json`** を読んで動きます
（`nashi.json` でも可）。エディタを使わず手で書いても構いません。

文字コードは **UTF-8**（BOM あり／なしどちらでも可）。Shift_JIS で書かれていた場合も
自動的に読み替えます。`//` と `/* */` のコメントも読み飛ばします。

## 全体の形

```jsonc
{
  "format": "nashi/1",

  "meta": {
    "name": "なしちゃん",          // ゴースト名
    "sakuraName": "なしちゃん",     // 本体の名前
    "keroName": "つぶ",            // 相方の名前
    "craftman": "作者名",
    "craftmanUrl": "",
    "homeUrl": "",                 // ネットワーク更新のありか（descript.txt の homeurl）
    "version": "1.0.0"
  },

  "settings": {
    "randomTalkEnabled": true,     // 自動でしゃべるか
    "randomTalkInterval": 180,     // 何秒ごとにしゃべるか（0 でしゃべらない）
    "noRepeatCount": 0             // 直近いくつのトークを候補から外すか（0 でおまかせ）
  },

  "variables": [                   // 変数の初期値
    { "name": "好感度", "value": 0 }
  ],

  "scripts": [ /* 下記 */ ]
}
```

`meta` と `settings` は省略しても既定値で動きます。

## scripts

`scripts` は「帽子ブロック 1 つぶんのかたまり」の配列です。

```jsonc
// イベントに反応する
{ "id": "s1", "kind": "event", "event": "OnBoot", "weight": 1, "blocks": [ … ] }

// ランダムトーク
{ "id": "t1", "kind": "talk", "name": "ひとりごと", "weight": 2, "blocks": [ … ] }

// 名前で呼ばれる（選択肢の行き先、call ブロック）
{ "id": "f1", "kind": "function", "name": "なでられた", "blocks": [ … ] }

// さくらの頭をなでられたときだけ動く
{ "id": "s2", "kind": "event", "event": "OnNadeNade",
  "filter": { "area": "Head", "who": 0 }, "blocks": [ … ] }

// 5 秒ごとに動く（定常ループ）
{ "id": "s3", "kind": "event", "event": "OnSecondChange", "everySec": 5, "blocks": [ … ] }

// ほかのゴーストに「こんにちは」と話しかけられたときだけ動く
{ "id": "s4", "kind": "event", "event": "OnCommunicate",
  "filter": { "contains": "こんにちは" }, "blocks": [ … ] }
```

| キー | 意味 |
|---|---|
| `id` | 任意の識別子。ランダムトークの重複回避と、`call` の代替キーに使われます |
| `kind` | `event` / `talk` / `function`。それ以外（`loose` など）は無視されます |
| `event` | `kind: "event"` のときのイベント名 |
| `name` | `talk` / `function` の名前。`call` や選択肢の行き先で使います |
| `weight` | えらばれやすさ（既定 1）。同じイベントが複数あるとき、重み付きで抽選します |
| `everySec` | `OnSecondChange` を何秒ごとに動かすか（省略＝毎秒）。SSP は毎秒送ってくるので、栞側で間引きます |
| `filter` | イベントのしぼり込み。マウス系は `area`（当たり判定名 `Head` / `Face` / `Bust` / `Skirt` / `Hand`）と `who`（`0`＝本体・`1`＝相方）。`OnCommunicate` は `from`（相手の名前）と `contains`（言われたことにふくまれる言葉）で、どちらも**ふくんでいれば一致**。省略した項目は「どこでも／だれでも／なんでも」 |
| `disabled` | `true` にすると無効化されます |
| `x` / `y` | エディタ上の位置。栞は無視します |

`blocks` の中身は [ブロック一覧](blocks.md) を参照してください。

## 動きのきまり

* **イベントの抽選** — 同じ `event` のスクリプトが複数あるときは重み付きで 1 つ選びます。
  直前に選んだものは候補から外すので、同じ反応が 2 回続きません。
  選んだものが何も出力しなかった場合は、別のものを最大 4 回まで試します。
* **ランダムトーク** — `OnSecondChange` を数え、`randomTalkInterval` 秒たったら
  `kind: "talk"` から重み付きで 1 つ選んで再生します。
  **直近に出したものは候補から外します**（外す数は `noRepeatCount`。0 のときは
  トーク数の半分・最大 8）。外しすぎて候補が無くなるときは、古いほうから戻します。
  出した順番は `nashi_save.json` に残るので、起動しなおした直後も繰り返しません。
  SSP が「いましゃべってはいけない」状態（`Reference1` が `1` 以外）のときは待ちます。
  何かをしゃべると、タイマーはリセットされます。
* **くりかえしの間隔** — `everySec` があるスクリプトは、起動してからの秒数がその倍数の
  ときだけ動きます。毎秒まるごと動かすとそれだけで重くなるので、
  「◯秒ごと」を宣言してもらう形にしています。
* **しぼり込み** — `filter` があるスクリプトは、その条件に合ったときだけ候補になります
  （マウス系は `Reference4`＝当たった場所と `Reference3`＝相手、`OnCommunicate` は
  `Reference0`＝相手の名前と `Reference1`＝言われたこと）。
  一致するものが 1 つも無いときは既定の反応が返ります。
* **細かい条件が優先** — 同じイベントに `filter` 付きと `filter` 無しの両方があるときは、
  **条件を書いたほうだけ**が候補になります（「『こんにちは』と話しかけられたとき」は
  「話しかけられたとき」より先）。条件付きが複数あるときは、その中で重み付き抽選です。
* **ゴースト間通信** — `OnCommunicate` は `Reference0`＝相手の名前
  （SSP の通信ボックスからなら `user`）、`Reference1`＝言われたこと、です。
  こちらから話しかけるときは `communicate` ブロックを使います。栞は応答に
  `Reference0: 相手の名前` を付け、SSP がそれを相手の `OnCommunicate` として届けます。
  いっしょに `Age`（やりとりの世代数。初回 0、返すたびに +1）も付けるので、
  SSP 側でも長すぎる会話を止められます。
  栞自身も、話しかけ合いが 8 往復続いたら、しゃべるだけにして通信を打ち切ります
  （ゴースト同士が延々と会話し続けるのを防ぐため）。
* **なでなで** — `OnMouseMove` が同じ場所の上で 8 回続くと、栞が **`OnNadeNade`** という
  イベントを自分で作って実行します（1.5 秒あくか、場所が変わるとリセット）。
  SSP がこの名前のイベントを送ってくるわけではありません。当たり判定の外は数えません。
* **選択肢** — `\q[表示,ID]` の ID と同じ `name`（または `id`）を持つ
  `function` / `talk` が `OnChoiceSelect` で実行されます。
* **終了** — `OnClose` / `OnCloseAll` の応答には `\-` が必ず付きます
  （書き忘れてもゴーストが終了できなくなりません）。
* **`\e` の補完** — 出力の末尾に `\e` も `\-` もない場合、`\e` を足します。
* **保存** — 変数は `nashi_save.json` に保存されます（終了時・2 分ごと）。
  保存された値はプロジェクトの初期値より優先されます。
  やり直したいときは `nashi_save.json` を消してください。
* **自動読み直し** — `ghost.json` の更新を 3 秒おきに見ていて、
  変わっていれば SSP を止めずに読み直します。
  そのとき、新しく増えた変数だけが初期値付きで追加されます。

## ブロックがないときの既定動作

対応するスクリプトが 1 つもないイベントには、控えめな既定の応答を返します。

| イベント | 既定の応答 |
|---|---|
| `OnFirstBoot` | 「はじめまして。…です。よろしくね。」 |
| `OnBoot` | 「おかえりなさい。」 |
| `OnClose` / `OnCloseAll` | 「またね。」＋`\-` |
| `OnMouseDoubleClick` | 「なに？」など 3 種からランダム |
| その他 | 応答なし（204 No Content） |

`ghost.json` が読めなかったときは、起動時にその旨とエラー内容をしゃべります。

## デバッグ

`nashi.dll` と同じフォルダに空の **`nashi_debug.txt`** を作っておくと、
読み込み結果や再読み込みのログがそこに追記されます。
